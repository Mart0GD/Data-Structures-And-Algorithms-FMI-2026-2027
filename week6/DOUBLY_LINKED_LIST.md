# Двусвързан списък

Двусвързаният списък е естественото продължение на едносвързания, с цел да направи структурата по-удобна за използване. Можем да си представим, че имаме два едносвързани списъка, като единият от дях е обърнат.

## Singly Linked List vs Doubly Linked List

| Операция / Свойства | Едносвързан списък (Singly Linked List) | Двусвързан списък (Doubly Linked List) |
| :--- | :--- | :--- |
| **Добавяне в началото** | $O(1)$ | $O(1)$ |
| **Добавяне в края** | $O(1)$ *(при наличен `tail`)* | $O(1)$ *(при наличен `tail`)* |
| **Добавяне в средата** *(при известен указател)* | $O(1)$ | $O(1)$ |
| **Премахване от началото** | $O(1)$ | $O(1)$ |
| **Премахване от края** | $O(N)$ *(изисква обхождане до предпоследния)* | $O(1)$ |
| **Премахване от средата** *(при известен указател)* | $O(N)$ *(за намиране на предходния)* / $O(1)$ *(ако се трие по стойност със сменяне)* | $O(1)$ |
| **Итерация / Обхождане** | Напред  | Двупосочно |
| **Памет за указатели** | 1 указател на възел (`next`) | 2 указателя на възел (`next` и `prev`) |

Всеки възел държи в себе си по два указателя. Това може да се окаже контрапродукивно за малки по размер типове като **char**, тъй като ще харчим по 16 байта (64 битова система) за един символ в списъка!

## Цикличен двусвързан списък

От тук насетне всеки двусвързан списък ще разглеждаме като цикличен. Като това означава, че всеки елемент има предшественик и наследник. За целта имаме два общи начина, по които да подходим:

**Използване на отделни head и tail**

~~~.cpp
    class list
    {
        ...
    private:
        node *head, *tail;
    }; 
~~~

Можем да използваме отделни указатели за начало и край на списъка. Това обаче ще доведе до постоянното "поддържане" на указателите за начало и край, което утежнява сравнително много логиката и много лесно може да се избегне със следващото предложение.

**Стекови sentinel елемент**

Ще използваме стекови възел `sentinel`, който ще служи като мост. Негов следващ елемент ще бъде първият елемент на списъка (head), а предишният му елемент ще бъде последния (tail). Така този елемент наистина е "мост" между двата края на списъка без да плащаме двоината цена за това. 

Друго, чрез sentinel елемента избягваме изцляло `nullptr` като стойност, тъй като при празен списък: 

`sentinel.next = &sentinel`  
`sentinel.prev = &sentinel`  

Така **всеки елемент** име предшественик и наследник и не трябва да се боим вече от edge case-ове. 

Ето за сравнение как изглежда вече операцията за премахване на елемент със и без sentinel елемент :

~~~.cpp
    // без sentinel
    template<typename T>
    void popAt(iterator itt)
    {
        if(empty()) throw "List empty!";
        if(!itt) throw "Invalid position!";
    
        if(head == tail && head = itt.ptr)
        {
            delete head;
            head = tail = nullptr;
            return;
        }
    
        node*& n = itt.ptr;
    
        n->prev->next = n->next;
        n->next->prev = n->prev;
    
        if(n == head) head = head->next;
        if(n == tail) tail = tail->prev;
        
        delete n;
    }

    // със sentinel 
    template<typename T>
    void popAt(iterator itt)
    {
        if(empty()) throw std::out_of_bounds("List empty!"); 
    
        node*& n = itt.ptr;
    
        n->prev->next = n->next;
        n->next->prev = n->prev;
    
        delete n;
    }
~~~

## Задачи за упражнение

**Задача 1**

Даден е указател към началния елемент на двусвързан списък. Да се реализира функция, която премахва от списъка всички елементи, чиято стойност е равна на сумата от стойностите на техните непосредствени съседи (предишен и следващ елемент).

~~~
Пример:
Вход:  1 -> 2 -> 5 -> 3 -> 1 -> 0 -> 0 -> 0
Изход: 1 -> 2 -> 1 -> 0 -> 0
~~~

**Задача 2**

Даден е указател към елемент на сортиран цикличен двусвързан списък, които е бил ротиран (изместен). Напишете програма, която намира и връща началото (head елемента) на този списък.

~~~
Пример:
Вход: 16 17 19 5 6 7 8 9 15 
                 ^-> старт
Изход: 5
~~~
